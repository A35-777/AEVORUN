Integration Guide

Getting Started with AEVORUN

Learn how to analyze Python source code from the command line, integrate with your pytest test runner, or run the Python SDK.

1. Installation

AEVORUN requires Python 3.10+ and standard PyTorch (CPU-only is fully sufficient). 

# Install via pip
pip install aevorun

# Or clone from GitHub for local development
git clone https://github.com/A35-777/AEVORUN.git
cd AEVORUN
pip install -e .

2. Command-Line Interface (CLI)

Run the aevorun CLI on any Python file or directory: 

# Analyze a single file
aevorun analyze src/services/billing.py

# Format output as JSON for CI pipeline ingestion
aevorun analyze src/services/billing.py --format json

# Filter recommendations by confidence threshold
aevorun analyze src/services/billing.py --threshold 0.75

# Display model and checkpoint metadata
aevorun info

3. Python SDK Usage

Directly invoke the AEVORUN-T1 engine programmatically in your testing harnesses: 

from aevorun import Aevorun

# Initialize engine (loads default AEVORUN-T1 checkpoint)
engine = Aevorun()

source_code = """
from datetime import datetime, timedelta

def get_next_run(last_run: datetime) -> datetime:
    return last_run + timedelta(days=30)
"""

# Analyze function AST
results = engine.analyze_source(source_code)

for func_name, analysis in results.items():
    print(f"Function: {func_name}")
    print(f"Is Temporal: {analysis.is_temporal}")
    for rank, scenario in enumerate(analysis.scenarios, 1):
        print(f"  #{rank}: {scenario.name} (confidence: {scenario.score:.2f})")
        print(f"     Clue: {scenario.evidence}")

4. Pytest Test-Prioritization Pattern

Use AEVORUN to dynamically verify that critical temporal edge cases are covered by your test suite: 

import pytest
from aevorun import Aevorun
import my_module

def test_temporal_coverage():
    engine = Aevorun()
    analysis = engine.analyze_file("src/my_module.py")
    
    # Assert that all critical temporal functions have matching test scenarios
    for func, res in analysis.items():
        if res.is_temporal:
            top_scenario = res.scenarios[0].id
            print(f"Warning: Ensure tests probe {top_scenario} for {func}")
