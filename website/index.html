The Real Research Problem

Why temporal defects slip past conventional testing suites

📅

Irregular Calendar Boundaries

February 29 leap years, variable 28/29/30/31 month lengths, and ISO week-numbering annual rollovers break naive duration addition (e.g. timedelta(days=30)).

🌐

Timezone Offset Ambiguities

Converting between local time and UTC frequently introduces naive vs. aware mismatches (raising TypeError) or corrupts database timestamps.

⚡

Daylight Saving Discontinuities

Spring-forward transitions skip 1 hour entirely (nonexistent local civil times), while autumn transitions repeat 1 hour (ambiguous local times requiring fold=0/1).

Developer SDK & CLI

Run completely offline with zero API keys or cloud dependencies

Python SDK

from aevorun import Aevorun

model = Aevorun()

result = model.analyze_source("""
def next_run(last_run):
    return last_run + timedelta(days=1)
""")

for scenario in result.scenarios:
    print(f"[{scenario.rank}] {scenario.name}: {scenario.score:.2f}")
    print(f"    Test with: {scenario.recommended_test_dates[0]}")

Command Line Interface

# Analyze a python file
aevorun analyze src/billing.py

# Filter top 3 scenarios as JSON
aevorun analyze src/billing.py --top-k 3 --json

# Inspect model checkpoint & architecture
aevorun info

# Show version
aevorun version
