RQ1: Neural vs. Static Rules

Static heuristics achieved 0.7130 F1 but suffered a disastrous 75.0% false-positive rate on non-temporal code due to lexical token collisions (e.g. mathematical delta). AEVORUN-T1 achieved 0.0% FPR while boosting F1 to 0.8760.

RQ2: Ranking Precision (Recall@3)

In practical testing, developers only inspect the top 2-3 recommended scenarios. AEVORUN-T1 captured the true failing temporal scenario in the top 3 recommendations in 93.7% of all cases, outperforming GBDT (87.5%).

RQ3: Generalization Across Repositories

Evaluation was conducted on repositories never seen during training: apache/airflow, certbot/certbot, boto/botocore, chronos, and token-vault. Performance remained stable within ±3.2% of validation scores.
