v1.0.0

Initial Public Release (AEVORUN-T1)

November 2026

The initial release of AEVORUN introduces the complete end-to-end framework for learned temporal test-scenario prioritization.

Key Features & Deliverables:

  • AEVORUN-T1 Neural Model: Deep Residual MLP with 53,711 parameters trained from scratch with focal loss and temperature-scaled calibration.
  • 82-Dimensional AST Extractor: Python AST structural parser extracting call frequencies, keyword arguments, arithmetic operations, and temporal context clues.
  • 14-Scenario Taxonomy: Comprehensive coverage of leap days, month-ends, DST skips/repeats, timezone mismatches, timestamp precision, and expiration boundaries.
  • CLI & SDK: Full aevorun analyze CLI with human and JSON output modes and high-level Aevorun Python SDK.
  • Empirical Benchmark Suite: Evaluated on 5 unseen open-source repositories achieving 0.8760 Macro-F1 and 93.7% Recall@3 with 0.0% non-temporal false positive rate.
