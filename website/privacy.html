Zero Telemetry

Local-First Privacy Policy

Your source code never leaves your computer. AEVORUN is built from the ground up for strict privacy and complete offline execution.

1. 100% Offline Execution

The AEVORUN CLI and Python SDK execute exclusively on your local CPU. When you run aevorun analyze, no network connections are made, no packets are transmitted, and no code snippets are sent to external servers or cloud AI APIs.

2. Zero Telemetry or Analytics

AEVORUN contains no telemetry SDKs, no usage trackers, and no background crash reporting pings. We do not collect your IP address, environment details, or codebase metadata.

3. Static Site Privacy

The documentation site hosted on Cloudflare Pages is a static client-side web application. The interactive code analyzer executes directly in your web browser's JavaScript runtime; no code pasted into the demo is stored or transmitted.
