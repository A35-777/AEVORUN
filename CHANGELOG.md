# Changelog

All notable changes to the AEVORUN project are documented here.

## [0.1.0] - 2026-11-22

### Initial Release
- **Model:** AEVORUN-T1 compact neural network (53,711 parameters).
- **Features:** 82-dimensional AST structural and temporal code representations.
- **Taxonomy:** 14 temporal edge-case scenario categories with recommended test dates.
- **Baselines:** Frequency baseline, static heuristics, Logistic Regression, and Gradient Boosted Trees.
- **Benchmarks:** Independent evaluations over strictly held-out open-source repositories.
- **SDK & CLI:** Complete offline Python SDK (`aevorun`) and CLI interface.
- **Website:** Cloudflare Pages-compatible static presentation site with interactive model explorer.
